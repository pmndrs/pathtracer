Animation workshop

Train an elbow correction.

When a character bends an arm, a corrective shape can restore volume near the joint. Build a small network that predicts how strongly to apply that shape, then watch what happens on a motion it has never seen.

Step 1 / Collect examples

Give the network an answer key

A blendshape stores offsets for mesh vertices. Its drive is a number between 0 and 1. On this rig a drive of 0.50 moves our elbow marker 10 mm along its correction direction. “Drive” is the answer for one pose. The MLP also has internal weights, which stay the same as you scrub between poses.

In a production rig, pose the character, let the artist set the corrective drive, and export the joint angles and approved drive together. Here a small synthetic rig stands in for the artist. Click each sweep to capture 13 labeled poses, from 0° to 120° of bend in 10° increments. Each sweep holds a different forearm twist.

Step 2 / Choose the inputs

What can the model see?

Read the 90° rows. If the input is just [90], those poses look identical to the network even though the labels differ. More training cannot tell it which answer you meant. Forearm twist is available on the skeleton at playback time, so it is a candidate second input.

Build the input vector
x = [bend / 120]
1 input → 8 ReLU neurons → 1 drive
25 trainable parameters

Dividing bend by 120 and twist by 60 keeps the numbers small. The two-input model needs eight extra weights, one connection from twist to each hidden neuron. Neither the frame number nor the rig’s answer is an input. For a different rig, think about whether two poses with identical inputs could need different corrections.

Step 3 / Fit the model

Learn from the captured curls

Start with bend only and all three sweeps. Train 500 steps. At each step, the model predicts each captured drive, averages the squared errors, and adjusts every weight and bias using the loss gradient. Switch to bend + twist and train for the same number of steps. Each input choice has its own model. Switch back to revisit its predictions. Both models train on the same captured data.

Build the same experiment in code

In a checkout of this repository, save this as try-elbow.mjs next to examples/learn/nrc/elbow/model.ts. From that folder run node --experimental-strip-types try-elbow.mjs with Node 22.22 or newer. Try changing the inputs or removing a sweep and predict which frames will get worse.

import { makeModel, reach, recordSweep } from './model.ts'

const training = [-60, 0, 60].flatMap(recordSweep)
const model = makeModel('both') // try 'bend' next
model.train(training, 500)

const errors = reach.map(pose => {
  const drive = model.predict(pose)
  return 20 * Math.abs(drive - pose.target) // mm
})
console.log('Worst reach error in mm', Math.max(...errors))

To use your own data, replace the generated sweeps with exported rows like { bend: 90, twist: 60, target: 0.70 }. Keep the same angle units and joint coordinate system during playback. At runtime the call is just model.predict({ bend, twist }). Apply that drive to the corrective shape.

Step 4 / Check the result

Test a different movement

The evaluation clip is a 61-frame reach. Bend and twist change together, passing through twists between the captured sweeps. Every frame stays out of training. Holding out a whole movement gives you a stronger check than shuffling neighboring frames from one clip into both sets.

Decide whether to use it. For this exercise, give the rig a 2 mm worst-frame budget. Does the model beat an interpolated bend table and stay within budget? Scrub around the worst frame for a visible pop. Before shipping a real rig, use additional untouched clips, inspect the whole mesh, and time the model against the original rig. Try a data-coverage experiment
Clear the captures. Record only the neutral sweep, choose both inputs and train. That sweep never varies twist, so it cannot teach the effect of twist. Add both twisted sweeps, retrain, and compare the reach error. Capturing new data clears previous scores so every row in the table uses the same training set.
