Everything below is exported from `@pmndrs/pathtracer`. Types are listed where you write them yourself; result types are named in the row of the function that returns them. Rows marked **experimental** can still change. The source is in [`packages/pathtracer/src`](https://github.com/pmndrs/pathtracer/tree/main/packages/pathtracer/src).

The package also exports the constants, binding numbers and WGSL fragments the kernels are built from. They are not listed here: you need them only to build your own pipeline layout around a kernel's text.

## Kernels

| Name | Kind | What |
| --- | --- | --- |
| `PtMegakernel` | class | One thread per pixel, one dispatch per sample pass. `create(device, caps, options)`. See [Megakernel](/pathtracer/megakernel). |
| `PtWavefront` | class | Small kernels joined by GPU queues; same API plus `finish()`, `memory()`, `maxPassesPerEncode()`, `kernelBytes`. See [Wavefront](/pathtracer/wavefront). |
| `PtMegakernelOptions` | type | Options of `PtMegakernel.create`. |
| `PtWavefrontOptions` | type | The megakernel's options plus `refill`, `refillThreshold`, `layers`, `appends`, `sort`. |
| `PtLimits` | type | `maxDepth`, `rrStartDepth`, `textureConeScale` for `setLimits`. |
| `PtLookAtCamera` | type | `position`, `target`, `up`, `yFovDeg` for `setCamera`. |
| `PtImage` | type | Result of `readImage`: `width`, `height`, `data` (RGBA `float32`), `samples`. |
| `ptwfAutoPolicy` | function | Picks the scheduler and its settings for a film, path length and device. |
| `ptwfAutoLayers` | function | The policy's `layers` for a film of `pixels` pixels. |
| `ptwfUnsupported` | function | Why the wavefront cannot compile these integrator options, or `null`. |
| `ptMegakernelBuild` | function | The megakernel's WGSL and source map, without a device. |
| `ptMegakernelWgsl` | function | The megakernel's WGSL only (for size checks). |
| `ptWavefrontBuild` | function | Every wavefront kernel's WGSL and source map. |
| `ptWavefrontKernelBytes` | function | WGSL bytes per kernel of a wavefront build. |
| `ptCameraBasis`, `ptCameraDirection` | function | The camera vectors the kernel uses, and the ray of a pixel position (CPU twins). |

## Scene options and modes

| Name | Kind | What |
| --- | --- | --- |
| `ptSceneOptions` | function | Kernel options that match a `GpuScene`, with your overrides merged in. |
| `PtSceneOptionsOverrides` | type | What `ptSceneOptions` takes: any kernel option plus `integrator`, `layered` and `materialProbes`. |
| `PtIntegratorOptions` | type | The integrator settings. See [Integrator options](/pathtracer/integrator-options). |
| `resolveIntegratorOptions` | function | The options with every default filled in; throws on invalid combinations. |
| `PtMaterialOptions`, `PtMaterialFeatures` | type | OpenPBR mode settings and the lobes to compile. |
| `ptMaterialFeatures` | function | The lobes a list of material records needs. |
| `PtLayeredOptions` | type | Layered BSDF settings (`layering`, `albedoBase`, `albedoCorrection`, ...). |
| `PtMode` | type | `'reference' \| 'preview' \| 'realtime'`. |
| `ptModePreset` | function | What a mode sets: integrator options, layering, limits, scene packing. |
| `ptModeNotes` | function | One status line per preset entry, for display. |
| `ptApplyMode` | function | Options with a mode's settings filled under your own (what `create` does). |

## Outputs

| Name | Kind | What |
| --- | --- | --- |
| `ptDecodeAovs` | function | Splits accumulator sums into a `PtAovs` (`albedo`, `normal`, `viewZ`, `coverage`). `readAovs` uses it. |
| `ptSummarizeCounters` | function | Means of raw counters: depth, rays, end reasons (`PtCounterSummary`). |
| `ptCounterImage` | function | One counter word per pixel, divided by the sample count, for a heat map. |
| `PT_COUNTER`, `PT_TERM`, `PT_TERM_NAMES` | const | Counter word indices and path end reasons. |
| `PtHooksOptions` | type | **Experimental.** WGSL path hooks (`ptOnVertex`, `ptTerminate`) and their bind group. |

## Real time

| Name | Kind | What |
| --- | --- | --- |
| `ptDecodeFrame` | function | Splits the beauty and the plane buffer into a `PtFrame`. `readFrame` uses it. |
| `PT_FRAME_PLANES` | const | Number of frame planes (7). |
| `PT_DEMOD_EPS` | const | Floor of the demodulation factors (0.001). |
| `ptFrameBase` | function | Wavefront: the `vec4f` index where the planes start in the accumulator. |
| `PtSamplerKind`, `PtBlueNoiseShift` | type | Sampler names and blue-noise shifts. |
| `ptSample2D`, `ptSampleBlueNoise`, `ptPixelSeed` | function | CPU twins of the samplers, for checks. |
| `PT_VBUFFER_FORMAT` | const | **Experimental.** `'rgba32uint'`, the V-buffer texture format. |
| `ptVbufferPack`, `ptVbufferUnpack` | function | **Experimental.** Encode and decode one V-buffer texel. |
| `ptVbufferResolve` | function | **Experimental.** CPU twin: the hit a V-buffer texel names. |

The blue-noise texture loaders, `fetchBlueNoise` and `decodeBlueNoisePng`, are in `@pmndrs/raytracer`.

## BSDF twins and WGSL builders

For tests, tools and your own kernels. The TypeScript functions are twins of the WGSL the kernels run.

| Name | Kind | What |
| --- | --- | --- |
| `ptDiffuse`, `ptConductor`, `ptDielectric`, `ptBlack` | function | BSDF parameters (`PtBsdfParams`) of the basic lobes. |
| `ptBsdfEval`, `ptBsdfPdf`, `ptBsdfSample` | function | Evaluate, get the density of, and sample a BSDF. |
| `ptBsdfFromMaterial` | function | A material record to BSDF parameters: legacy, or OpenPBR with `options`. |
| `ptBsdfReduced` | function | The reduced material of `materialLod: 'secondary'`. |
| `ptLayered`, `ptLayeredCoatedConductor` | function | Layered BSDF parameters: dielectric over diffuse, coat over metal. |
| `ptLayeredEval`, `ptLayeredPdf`, `ptLayeredSample` | function | The layered BSDF. |
| `ptLayeredAlbedo` | function | Directional albedo of a rough dielectric interface. |
| `ptFuzzedEval`, `ptFuzzedSample` | function | A base BSDF under the fuzz (sheen) layer. |
| `ptThinFilmAiry`, `ptFilmFresnel` | function | Thin-film reflectance. |
| `ptBsdfWgsl`, `ptLayeredWgsl`, `ptFuzzWgsl`, `ptThinFilmWgsl` | function | WGSL of the lobes. |
| `ptBsdfAdapterWgsl` | function | WGSL that turns a material record into BSDF parameters. |
| `ptShadingModulesWgsl` | function | Every scene-independent WGSL part both schedulers use, in order. |
| `ptIntegratorWgsl` | function | The megakernel's integrator WGSL. |
| `ptSamplerWgsl` | function | WGSL of a sampler. |

The ray tracing, scene copy and light sampling functions these build on are in `@pmndrs/raytracer`: see its [API reference](/raytracer/api).
