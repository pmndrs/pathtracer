The examples run in your browser: [open the gallery](https://pmndrs.github.io/pathtracer/examples/). Each page has its source on GitHub, linked from its top bar.

Run them locally with live library sources:

```sh
pnpm install
pnpm examples    # http://localhost:5310
```
