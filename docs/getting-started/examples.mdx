The examples run in your browser: [open the gallery](https://pmndrs.github.io/pathtracer/examples/). Each page has its source on GitHub, linked from its top bar.

Run them locally with live library sources:

```sh
pnpm install
pnpm examples    # http://localhost:5310
```

## Ray tracer

@pmndrs/raytracer on its own: rays in, hits out, in your own shaders.

| Example | What it shows | Status |
| --- | --- | --- |
| [Rays from your own shader](https://pmndrs.github.io/pathtracer/examples/raytracer/hits/) | What ray tracing adds to a raster pass: shadow, reflection and AO rays traced from every hit in your own compute shader. Click a pixel to see its rays. |  |
| [Ambient occlusion](https://pmndrs.github.io/pathtracer/examples/raytracer/ao/) | rtVisible, the cheapest query: cosine rays over the hemisphere ask only whether anything is within a radius. |  |
| [One-bounce shading](https://pmndrs.github.io/pathtracer/examples/raytracer/shade/) | rtShade at the first hit: emission and one light sample with its shadow ray, the lighting a reflection or GI effect needs. |  |
| [Batch tracing](https://pmndrs.github.io/pathtracer/examples/raytracer/batch/) | RtBatchTracer: camera rays and shadow rays from GPU buffers, hits and visibility back into GPU buffers, five passes and no readback. |  |
| [Interval queries](https://pmndrs.github.io/pathtracer/examples/raytracer/intervals/) | rtClosestInterval splits each ray into radiance-cascade intervals with no gap and no overlap. | **Experimental** |
