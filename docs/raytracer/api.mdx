Every name below is exported from `@pmndrs/raytracer`. WGSL functions are listed on the page that covers them. The source is in [`packages/raytracer/src`](https://github.com/pmndrs/pathtracer/blob/main/packages/raytracer/src); each export has a doc comment there.

Items marked **experimental** work and are checked, but their API can still change.

## Device and capabilities

See [Capabilities](/raytracer/capabilities).

| Name | Kind | What it does |
| --- | --- | --- |
| `detectCaps` | function | Reads an adapter's features and limits into a `Caps`. |
| `requestDeviceForCaps` | function | Requests a device with every useful feature and raised limits; returns `{ device, caps }`. |
| `buildCaps` | function | `Caps` from any adapter-like or device-like object (for example one with no features). |
| `featuresToRequest`, `limitsToRequest` | function | What `requestDeviceForCaps` would request. |
| `DEFAULT_LIMIT_CAPS` | constant | Ceilings on requested limits. |
| `capsHash` | function | Stable hash of everything that changes generated code: a pipeline cache key. |
| `deriveTier` | function | The tier label of a set of caps. Report it, never branch on it. |
| `Caps`, `RequestDeviceOptions`, `DeviceForCaps`, `Tier` | type | |

## Scene building

The input types are described in [Scenes](/concepts/scenes), [Materials](/concepts/materials) and [Lights](/concepts/lights).

| Name | Kind | What it does |
| --- | --- | --- |
| `buildGpuScene` | function | Builds the BVH and the scene copy from a `SceneCopyInput` and uploads both. Returns a `GpuScene`. |
| `GpuScene` | type | `trace`, `buffers`, `copy`, `format`, `packing`, `destroy()`. |
| `buildSceneCopy` | function | The CPU half: material, light and surface tables, textures. |
| `uploadSceneCopy` | function | Uploads a `SceneCopy` to storage buffers and texture arrays. |
| `writeSceneCopy` | function | Rewrites a rebuilt copy into existing buffers when it fits. |
| `createMaterial`, `defaultMaterial` | function | A full `RtMaterial` from a partial one; the OpenPBR defaults. |
| `makeSun`, `makeEnvironment` | function | Light records from `SunInput` and `EnvironmentInput`. |
| `buildTriangleLights` | function | The emissive-triangle lights of meshes and instances. |
| `lightSelectionWeights`, `parseLightSelection` | function | Light-selection strategies (`'pbrt'`, `'power'`, `'kind'`, capped). |
| `buildAliasTable`, `sampleAlias` | function | Vose alias table and its sampler (CPU). |
| `buildEnvMapTable`, `envMapMean` | function | Sampling tables and mean radiance of an equirect environment map. |
| `SceneCopyInput`, `SceneCopyMesh`, `SceneCopyInstance`, `SceneCopyOptions`, `RtMaterialInput`, `SunInput`, `EnvironmentInput`, `TextureInput`, `TextureOptions` | type | Inputs. |
| `SceneCopy`, `SceneCopyBuffers`, `RtMaterial`, `RtLight` | type | Outputs. |

## Scene copy in WGSL

See [Scene copy](/raytracer/scene-copy).

| --- | --- | --- |

| `rtSceneCopyBindGroupEntries` | function | The matching bind group entries for uploaded buffers. |
| `rtPackSceneAccess` | function | Rewrites WGSL written against the split buffers to read the packed one. |

| `rtSceneWgsl` | function | The scene-copy WGSL on its own (what `rtModuleWgsl` adds with `scene`). |

| `RtMipGenerator`, `SceneCopyPacking`, `TextureLayout` | type | |

## Tracing in WGSL

See [Inline WGSL](/raytracer/inline-wgsl).

| Name | Kind | What it does |
| --- | --- | --- |

| `RtModuleOptions` | type | Its options. |
| `sceneFormatOf` | function | The formats of bvh trace buffers, to spread into module and tracer options. |
| `rtWalkEntries` | function | Layout entries (without binding numbers) of the walk's buffers. |
| `withBindings` | function | Numbers module entries from a first binding. |
| `rtSceneBindGroupEntries` | function | Bind group entries of the walk for bvh trace buffers. |
| `rtModuleStorageBuffers` | function | Storage buffers a module adds to a kernel. |

| `SURFACE` | constant | The `RT_SURF_*` bit values. |
| `rtIsWideNodeFormat` | function | **Experimental.** True for the wide formats `bvh4` and `cwbvh8`. |
